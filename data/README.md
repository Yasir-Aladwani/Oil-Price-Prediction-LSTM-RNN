# Dataset

`Crude_Oil_Data.csv` (about 0.5 MB, 6,073 daily rows from 23 Aug 2000 to 30 Oct 2024) is included because the Streamlit dashboard reads it at runtime.

Source: the "Crude Oil Stock Dataset 2000-2024" on Kaggle:

https://www.kaggle.com/datasets/crude-oil-stock-dataset-2000-2024

The dataset is redistributed here for this educational project. Check the license on the Kaggle page before reusing it.

The app and the notebook expect the file at:

data/Crude_Oil_Data.csv
